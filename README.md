## Changes in this fork

The rest of this README is upstream's. This fork adds:

- **An Intel Mac CLI build.** [`.github/workflows/cli-darwin-x64.yml`](./.github/workflows/cli-darwin-x64.yml)
  builds `t3-<version>-darwin-x64.tar.gz` on an Intel runner, smoke-tests it, and can publish it
  as an unofficial prerelease with `SHA256SUMS`.
- **Updates from this fork.** `t3 update` accepts the `darwin-x64` archive and reads releases from
  the repository named by `T3CODE_UPDATE_REPOSITORY` (for example `ChyuWei/t3code`), for version
  discovery and downloads. `scripts/install.sh` reads the same variable.
  `T3CODE_RELEASE_BASE_URL` still takes precedence when set.
- **Opt-in telemetry.** Product usage events are off by default. Set
  `T3CODE_TELEMETRY_ENABLED=true` before starting the server to send them.

### Build and publish the Intel Mac CLI

1. Open **Actions → CLI (Intel Mac) → Run workflow** on `main`.
2. Leave `version` empty to use `apps/server/package.json`; keep `publish_release` enabled.
3. The run builds on `macos-26-intel`, then attaches `t3-<version>-darwin-x64.tar.gz` and
   `SHA256SUMS` to the `v<version>` release in this fork (prerelease) and uploads the
   `cli-darwin-x64` artifact.

### Install it on an Intel Mac

Point the installer at this fork and run it:

```sh
export T3CODE_UPDATE_REPOSITORY=ChyuWei/t3code
curl -fsSL https://raw.githubusercontent.com/ChyuWei/t3code/main/scripts/install.sh | sh
```

The installer reads version discovery and archives from `T3CODE_UPDATE_REPOSITORY` (default
`pingdotgg/t3code`), so it finds this fork's `darwin-x64` archive even though every release here is a
prerelease. Keep the export in your shell profile: `t3 update` reads the same variable. Pin a
version with `T3CODE_VERSION=0.1.11`, and set `T3CODE_INSTALL_BIN_DIR` if `~/.local/bin` is not on
your `PATH`.

T3 Code runs the coding agents on your machine and gives them one fast interface. Start a thread at your desk, then approve the next step from your phone.

It works with Claude Code, Codex, Cursor, OpenCode, Grok Build, Antigravity, Kiro, Pi, Muse Code, fx, and any [ACP](./docs/user/providers-acp.md) agent. If an agent is set up on your computer, T3 Code can control it.

## What you get

- **Your subscriptions.** T3 Code does not resell tokens. It drives the agents you are already signed in to.
- **Every agent in one place.** Change models in the middle of a thread. Let Claude hand a task to Codex.
- **Desktop, web, and phone.** One server, and every client shows the same threads. There are apps for iOS and Android.
- **Remote ready.** Run agents on any machine. Connect over your local network, Tailscale, or [T3 Connect](./docs/user/remote-access.md).
- **Git built in.** Each thread can work in its own worktree. Review the diff, then commit, push, and open a pull request with one button.
- **Fast.** Performance is a feature here. We measure it, and we treat a dropped frame as a bug.
- **Open.** Source code is MIT licensed. If you don't like something, fork it under your own branding (see [Trademarks and forks](#trademarks-and-forks)).

## Install

### Desktop app

[Download T3 Code](https://t3.codes/download) for macOS, Windows, or Linux. You can also use a package manager:

| Platform       | Command                                                              |
| -------------- | -------------------------------------------------------------------- |
| macOS          | `brew install --cask t3-code`                                        |
| Windows        | `winget install T3Tools.T3Code` or `scoop install extras/t3code`     |
| Arch Linux     | `yay -S t3code-bin`                                                  |
| Nix            | `nix profile add github:NixOS/nixpkgs/nixos-unstable#t3code`         |
| Debian, Ubuntu | `.deb` from [Releases](https://github.com/pingdotgg/t3code/releases) |

### Command line

This installs the `t3` command. Run `t3` to start the server and open the web app.

```bash
curl -fsSL https://t3.codes/install.sh | sh
```

On Windows, in PowerShell:

```powershell
irm https://t3.codes/install.ps1 | iex
```

To try it once without an install, run `npx t3@latest`.

### Phone

Get the app from the [App Store](https://apps.apple.com/us/app/t3-code-remote-claude-more/id6787819824) or [Google Play](https://play.google.com/store/apps/details?id=com.t3tools.t3code). Then follow [remote access](./docs/user/remote-access.md) to connect it to your computer.

### Sign in to an agent

T3 Code needs one agent that is installed and signed in. For example, install [Claude Code](https://claude.com/product/claude-code) and run `claude auth login`, or install [Codex CLI](https://developers.openai.com/codex/cli) and run `codex login`.

[Provider setup](./docs/user/install.md#providers) has the steps for each agent. [Install T3 Code](./docs/user/install.md) covers nightly builds, AppImage, WSL, and NixOS.

## "Wait, what are you selling me?"

Nothing. We built T3 Code because we wanted the best possible development experience with agents. We were inspired by existing solutions like the Codex desktop app, Conductor, Claude Desktop and Cursor Glass, but none met our bar.

We wanted something performant, remote-ready, and truly open. If we ever go the wrong direction, we want you to have everything you need to fork the source code and build the tool that you want, under your own name and branding.
